Три bash-скрипта, и один из них стирает систему (╯°□°）╯︵ ┻━┻

**[tan.sh](tan.sh)** считает тангенс угла.

**[test.sh](test.sh)** держит разрушительный сценарий как текст и разбирает его по косточкам. Ничего не выполняет.

**[oops.sh](oops.sh)** ( ͡° ͜ʖ ͡°) Вкусняшка:3

---

## Таблетки ಠ_ಠ

**Синяя.** `./tan.sh`, число на выходе, вкладка закрыта.

**Красная.** `./test.sh`, и узнаешь, что тут было.

Про красную: просто запусти и попробуй (＾▽＾)

---

## tan.sh

```bash
$ ./tan.sh
tan(30°) = 0.58

$ ./tan.sh 45
tan(45°) = 1.00

$ ./tan.sh 30 4
tan(30°) = 0.5774
```

## test.sh

Говорит и показывает. Ничего не трогает:

```bash
$ ./test.sh
```

Полный разбор по пунктам выводится прямо в терминал, так что дублировать его тут незачем (¬‿¬)

## Вкусняшка:3 (╯°□°）╯︵ ┻━┻

```bash
$ ./oops.sh
Этот скрипт стирает файловую систему. Разбор в test.sh.
```

Дальше нужен ключ, который надо вводить руками и очень осознанно.

## --demo

Считает, сколько файлов стёр бы сценарий из `test.sh`, по указанному пути. Вместе с `.git`. Ничего не пишет и не удаляет.

```bash
$ ./test.sh --demo .
```

## Если страшно (◕‿◕)

`test.sh` и `oops.sh` можно запускать в контейнере, хост они не видят:

```bash
$ docker run --rm -v "$PWD:/repo:ro" -w /repo bash:5.2 ./test.sh

$ docker run --rm -v "$PWD:/repo:ro" -w /repo bash:5.2 ./oops.sh
```

Монтирование read-only, так что записать в репозиторий нельзя даже теоретически.
